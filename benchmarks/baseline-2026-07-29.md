# Ronin performance baseline — 2026-07-29

This is the initial Wave-4 optimization baseline. It is a local comparative
measurement, not a release threshold; rerun noisy or surprising cases and
confirm semantic equivalence before treating a faster result as a win.

## Initial interpretation

Deep dependency-chain evaluation is the clear first performance problem:
Ronin is about 16.5 times slower than Ninja and 56.8 times slower than the C
reference on this workload. That supports the planned move away from repeated
recursive graph walks and reference-cloning adjacency toward ID-indexed,
iterative, memoized evaluation.

The scheduler-barrier workload is currently at parity with Ninja but about 20%
slower than the C reference. The other workloads are faster than this Ninja
build on this host, but those results must be rechecked after the compatibility
suite confirms that each tool is doing equivalent work.

The raw harness CSV for this run is reproducible with the command documented in
[`README.md`](README.md); this report preserves all metadata and samples needed
for later before/after comparisons.

The Ronin medians used by the executable regression gate are preserved in
[`baseline-v1.csv`](baseline-v1.csv).
